# Param Chawla’s Network Workshop

A static networking study workspace for Param Chawla, with 93 sidebar destinations, wireless tools, protocol models and guided courses.

## Features

IPv4/IPv6 addressing, VLSM, overlap and summary tools; ACL and prefix-policy builders; OSPF/BGP models; protocol timelines; packet and operational-output analysis; troubleshooting, quizzes and flashcards.

Wireless includes Wi-Fi 4–7 MCS rates within the stated model scope, FSPL band comparison with wall estimates and charts, RF/EIRP, airtime and Fresnel tools. Twenty original CWNA/CWAP/CWDP/CWSP/CWNE lessons open their own diagnostic practice scenarios.

Courses include 20 CCNA, eight CCNP and ten CCIE modules. Each includes explanations, reference tables, guided lab procedures, command examples, expected results, diagnostic feedback, notes and guide downloads. About Param contains the supplied professional biography and LinkedIn link.

## Verification and limits

Passed programmatic checks: 93 pages, 86 initial interactions, 118 detailed navigation checks; 38 course modules, 105 support/return transitions, 114 answer-feedback paths and 38 guide exports; 3,279 MCS rate/reference checks and all 20 CWNP scenario links; FSPL formulas, units, wall boundaries, charts and CSV controls.

The updated local version has not completed visual browser verification. PNG chart export needs a real-browser canvas check. These are educational browser models, not a live equipment emulator. Guided device labs require an appropriate isolated emulator and adaptation to its platform. Course material is independent study content, not official Cisco/CWNP courseware or a claim of complete exam-blueprint coverage. Only requested RIPE Stat lookups contact that external service. Local notes and browser-generated keys remain in the browser.
